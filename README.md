# Neuronal Heterogeneity and Degeneracy

Computational study of neuronal parameter heterogeneity and degeneracy using single-compartment models implemented in the **NEURON simulation environment**.

### Project Overview

* Developed a single-compartment neuronal model in NEURON.
* Hand-tuned the model parameters to match the firing rate obtained from experimental data.
* Computationally perturbed model parameters using MPMOSS to investigate their effects on firing-rate patterns.
* Analysed parameter-space **heterogeneity and degeneracy** under Wild-Type (WT) and Alzheimer's Disease (AD) conditions.
* Investigated how different combinations of biophysical parameters can produce similar firing-rate behaviours.

### Tools

* NEURON Simulation Environment
* Multi Parametric Multi Objective Stochastic Search(MPMOSS)
